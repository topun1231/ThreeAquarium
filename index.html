在 Wallpaper Engine 中打开

先点「同步到实时壁纸」，这里会显示这台电脑的壁纸地址。

在 Wallpaper Engine 选「打开壁纸 → 从 URL 打开」，粘贴地址。以后换缸只需在游戏里再次同步。

想在开机时等候鱼缸服务，可以下载 HTML 入口，在「打开壁纸 → 打开离线壁纸（动态）」中选它。

下载 Wallpaper Engine 入口

游戏标签可以关闭。想让鱼缸服务随 Windows 登录启动，双击项目里的「设置壁纸自启.cmd」；也可用「启动实时壁纸.cmd」手动启动。
