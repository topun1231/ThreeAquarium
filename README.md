# ThreeAquarium · 水草缸与水晶虾

在自己搭的缸里养虾。铺土、摆木石、种草、注水后，打开「虾册」领养第一批 7 只水晶虾。可以留着喜欢的个体，在主缸或繁育缸挑选亲虾，也可以选 1 只虾参加电脑对手的主题比赛。

## 启动正式版

安装 Node.js 22.12 或更高的 22.x 版本，在终端运行：

```sh
git clone https://github.com/topun1231/ThreeAquarium.git
cd ThreeAquarium
npm ci
npm run build
npm start
```

打开 [本机游戏](http://127.0.0.1:5173/)。首次构建生成 `dist/`，正式服务同时读取仓库里的 `public/assets/`。更新源码后重新构建并刷新页面即可。

## 怎么玩

- **造景**　从底床、木石和植物目录选材。点击放下木石后可以看到它下落、倾倒和停稳。右键或 Esc 取消当前放置，已放好的物件可以选中再移动。造景支持撤销和重做。
- **照料**　在缸里选位置加餐。饲料落到木石、水草或底床以后，打开「照料」里的「本缸最近一次加餐」，可以看到当时在落点附近吃过东西的虾。点名字就能找到它，已经静养或转让的虾会打开对应档案。每口缸分别记录，再次成功投喂时换成新一餐。
- **看一只虾**　在缸里点中它，再点缸边照片上的「细看」，就能看全身、头部和背纹。虾册里的大照片也可以点开。在虾册看中某块斑纹，点照片下的缸名就能带着这张近照去找它。
- **看幼虾**　点孵化消息，去这一窝住的缸找小虾。在缸里点中一只，展开「和双亲比一比」，可以自选母虾或公虾。点「并排细看」看头部或背纹，合上近照后直接点同窝另一只，还能用刚才的亲虾和部位接着比。同窝分住几口缸时，也可以跟着找过去。想给眼前这一只留影，就点名字旁的「拍照」，给照片写一句。
- 在缸里点刚孵出一窝的母虾，再点「看它的幼虾」也能翻同窝照片。点「回看母虾」可以回去。过一阵再点孩子，展开「对照小时候和双亲」，能看见它从刚孵化到眼前长了多少。同窝手记也能回看刚孵化或长到一半时的模样。
- **再看你拍的那只**　点成年消息，或翻到这窝的手记，展开「我给这窝拍的照片」。选一张自己的旧照，就能读到拍摄时的留言。想认一认它现在的样子，可以带着旧照去它现在住的缸自己找。
- **挑亲虾**　在缸里点一只空闲的成年水晶虾，再点「为它挑搭档」。它的照片会留在手边，点照片下方的缸名就能去另一口缸找。点中第二只后可「并排细看」，按 Esc 可结束挑选。选它作搭档后仍可修改草稿，点「安排这一窝」才会把亲虾移入选定的缸，给后代预留位置。新一窝默认安排在先选的亲虾所住的缸，自家育成的虾会带上出生那窝的目标。若先选的亲虾已在草稿中，则沿用草稿里的缸和目标。从同窝手记点「用它育下一代」会沿用手记里的比较项。想看配出目标花色的机会时，勾选「按目标排序并比较品质」。
- **比较两只备选**　在挑公虾或母虾的名单里，点一只，再点「和另一只对照」。点第二只后，就能并排看它们的全身、头部、背纹和自己写的观察。点其中一张照片下方的按钮就选它做亲虾。也可以返回名单，留着左边那只，换一只再看。
- **找收藏虾**　点缸边虾群状态里的「收藏」，能看到每只在缸收藏虾的名字和所在缸。点名字就会切到它所在的缸并跟随它。静养的虾可以从虾册的「静养处」查看。
- **到集市试配**　已经选好一只亲虾时，在挑搭档的名单上可以点「去集市看搭档」。集市会带上这只虾和原来的目标。想继续在自家虾里挑，点「返回挑搭档」。买入后可以带这对回选育，确认安排才开始繁育。
- **静观与壁纸**　在「观察」里选「长时间静观」，可一直观看当前的缸，按 Esc 或 H 返回。展开「保存图片或视频」，点「录制整缸视频（MP4）」按当前显示器的比例录下整缸远景，窗口缩小也能录制。常规输出长边最多 1920 像素、短边最多 1080 像素，实际尺寸在录制时显示。保持页面可见，最多 30 秒，也可提前结束。点「保存『缸名』的 MP4」下载后，可在 Wallpaper Engine 中作为本地视频打开。主缸视频的文件名以 `aquarium-main-` 开头，后面是录制时间。旧视频在本地能播、在 Wallpaper Engine 打开却黑屏时，可先改成 `aquarium.mp4` 再打开。视频记录录制时的缸景，之后改动造景可重新录制。
- **选育**　每窝可安排 2 或 4 只。选好双亲后，可记下想要的花色，也可挑一项想改善的品质，例如让孩子的覆盖超过双亲。挑到一半关掉游戏，同一浏览器重开这份存档后，可以从缸边的「选亲草稿」接着挑。双亲齐了会先回到配对摘要，按下「安排」才开始。有成长消息或正在养的一窝时，缸边优先显示它们，进「选育」仍可续选。如果有亲虾已去静养或正参与繁育，补选空位即可。双亲中已有一只拿到 9 分时，目标改为保持满分。成年后点「查看同窝对照」，能看到每只孩子达到了哪项目标；挑下一对时，展开「过往配对」还能比较这只亲虾和不同伴侣的结果。所有缸合计最多 50 只。
- **参赛**　在缸里点一只成年水晶虾，选「带它去常规赛」。自育虾收到本窝邀请时，可以点「去看本窝新秀赛」。常规赛、专题赛和新秀赛报名时，选好一只后可以展开「比较另一只候选虾」。两张近照可以一起放大看全身、头部或背纹，照片旁有各自的名字和你写的观察。想看活虾，可以去它的缸里找它。想知道它们在本场能拿几分，可以勾「查看赛前估分」。点写着虾名字的确认按钮才正式参赛。新秀赛能回看同窝兄弟姐妹和当初的育种目标。赛后可以带参赛虾去挑搭档，也能在缸边回看最近一场成绩。个体档案保留每张赛卡的名次与评语，静养、转让或纪录被超过后仍能翻看。早期存档可以恢复当时保存的赛卡最佳记录。
- **每窝新秀赛**　每窝自育虾成年后，会收到一份一直有效的邀请。在「比赛」或该窝手记里，挑一只仍在缸里的孩子代表这一窝。赛前可比较同窝的估分和三只电脑对手。换候选或过几天回来，对手相同。每窝只能参赛一次，成绩会跟着这只虾保留。赛后对照会分别显示参赛成绩和其他兄妹的估分。
- **轮换专题赛**　第一批水晶虾入缸后，在「比赛」可以参加首届专题赛。每届选一只在缸成虾，和三只固定的电脑对手比。颜色与纹样轮换，入门赛和进阶赛交替出现。参加一届后，过两小时开放下一届。未报名的邀请一直保留，离线只会等着当前一届。赛绩可以从比赛名单或参赛虾的档案回看，缸边卡显示这只虾最近的成绩。
- **家族相册**　在「同窝对照」里挑一只成年孩子作代表，点「看它的相册页」，或从虾册上方的「相册」回来翻看。照片下方会写出它有没有达到这窝当初的期待，还能直接去它所在的缸找它。「保存纪念图」可下载这只虾的肖像、双亲、三项品质及选育结果。静养或转让过的代表可以打开对应档案。首次收录的五个不同窝各有 40 金币鉴赏金，之后仍可收录或更换代表。
- **缸边留影**　在缸里选中一只虾，点「拍照」，可以写一句当时看中了哪里，也可直接「收进相册」。打开照片，点「和另一张留影对照」，自己挑第二张看花纹和当时的留言。相册满了也可以先拿刚拍的照片比较，再决定留哪张。在虾册的「相册」里还能补写或清空留言，或从自己养出的虾翻回它出生的那一窝。
- 想认一认小时候拍过的虾，打开那张留影，点「拿着旧照去…自己找」。到了它现在住的缸，旧照片和你的留言会留在手边。点哪只就看哪只，也可以返回整缸再找。点「拍一张对照」会把眼前的虾放在旧照旁边，喜欢这张再收进相册。
- **我的选育手记**　在虾册里挑一只水晶虾，展开「查看家系」，点「从它开始写选育手记」起个名字。到「相册 → 我的选育手记 → 挑后代」翻看它的子孙，点「和起点并排看」比较近照，喜欢哪只就把它记进来。可以隔代挑，也可以从后代的家系直接翻回对应的手记。想带它参赛时，展开「这一支的参赛记录」，就能翻到亲虾在同场留下的成绩。点名下一位选手后，在赛场确认报名。
- **自己挑两只比花纹**　在「查看家系」或手记里点「挑另一只并排看」，翻到想看的那一窝，再点一只虾。两张近照能一起看头部、背纹或全身。「留下右边这只，接着比」可以带着新挑的虾继续翻。去缸里看它后，点「返回这两只的近照」就能接着看刚才的部位。看中可以配对的一公一母，点「带这两只去选育」。如果草稿里原本挑了其他亲虾，会先显示它们的名字。最后点「安排这一窝」才会搬虾、预留位置。
- **腾位**　选好亲虾后，如果这口缸空间不足，可以在选亲页挑一只闲置成虾，指定接收缸后移入。原配对仍等你确认。活虾和未孵化预留合计达到 50 位时，可以暂停繁育，照常观赏或参赛。
- **缸位与扩缸**　主缸固定在窗边木柜。右侧繁育架的上层左、上层右、下层左，依次安放第一至第三口繁育缸。下层右侧放养护用品。打开缸边「缸位图」可以看到下一个缸位，买下后点缸名即可前往布置。
- **自愿转让**　在「买虾 / 扩缸」展开「自愿转让成虾」，选缸并勾选想送走的个体。按编号和品质核对名单后可以返回重选，确认后每只获得 8 金币并永久离缸，家系和赛绩仍可回看。选亲缺位置时也能直接进入，刚挑好的双亲会留在缸里。
- **查看家系**　在个体档案展开「查看家系」，可以找到父母和已孵化的孩子。同名个体按身份编号区分。浏览亲属后可以返回起点，继续原来的搜索或挑亲。
- **静养**　在虾册挑一只空闲成虾，展开「名字、移缸与静养」即可送去静养。共有 4 位，收藏虾也能入住。想接它回来时，筛选「静养处」，挑一口已注水且有空位的缸。安置和接回都免费，静养期间保留它的肖像、家系、收藏和比赛成绩。

游戏自动保存在当前浏览器。更换设备、浏览器或清理网站数据前，请在游戏内导出 JSON。旧进度首次合并时会先备份原缸。已有的观赏虾保留各自的名字和身份。

## 开发和验证

**静态桌面壁纸**　在「观察」展开「保存图片或视频」，点「保存整缸图片（PNG）」即可下载 PNG。图片按当前屏幕的比例和像素尺寸重新绘制，最多约 830 万像素。缩小游戏窗口或暂停模拟也可以拍；录制视频期间留影沿用视频尺寸。下载后可直接设为系统桌面背景。

**实时桌面壁纸**　点底部工具栏的「壁纸」可预看当前鱼缸。在预看里或「观察」面板中点「同步到实时壁纸」。首次同步后会展开桌面设置。在 Windows 上启动 Wallpaper Engine 后，可点「窗口试播『缸名』」。试播窗口按游戏所在屏幕的比例播放上次同步的鱼缸，关闭窗口即可结束试播。想放到桌面时，在「目标屏幕」填入序号，再点带屏号的设置按钮。游戏从 1 开始计数，对应 Wallpaper Engine 从 0 开始的顺序。多块屏幕播放同一份已同步的缸景。由游戏设置的入口会分别回报各屏是否载入这版。旧入口可以继续播放，重新用游戏设置一次后可查看分屏回执。使用拆分屏幕等自定义布局时，也可以复制下方地址到 Wallpaper Engine 里手动选屏，手动入口回报缸景的整体状态。[Wallpaper Engine 官方命令说明](https://help.wallpaperengine.io/en/functionality/cli.html#open-wallpaper)

鱼缸服务接收设置请求后，这个浏览器会记住屏号。下次打开会预选同一屏；如果重新排列过显示器，请按 Wallpaper Engine 当前的顺序核对按钮上的屏号。

扩缸后，「观察」会点名哪些邻缸还没同步。整组缸远景会显示各缸的灯具、开关状态和已经落位的虾，注水的邻缸也有随时间轻动的水面。实时壁纸会为刚移入或孵化的虾检查展示位置。选用整组取景时，邻缸路线准备好后，虾也会在底床和木石间活动。这些活动发生在壁纸副本里，进入游戏照料时仍接着游戏存档。调整后可以回到原先观察的缸，再点「同步到实时壁纸」。已打开的实时壁纸会在新缸景绘制成功后回报。

壁纸数据目录含中文时，游戏会尝试用英文路径打开同一份入口。若系统提示路径不可用，可在 Wallpaper Engine 中粘贴面板里的壁纸地址。想在游戏服务关闭时也看到留影，可把下载的 HTML 放进全英文路径，再从 Wallpaper Engine 打开。

要看当前游戏里的整缸远景，点底部「壁纸」。可选择跟随屏幕、横屏 16:9、宽屏 21:9 或竖屏 9:16。横屏下勾选「整组缸远景」，可以把窗边主缸和右侧繁育架一起放进画面，当前缸的虾继续活动。取景可同步到实时壁纸，也可导出 PNG 或 MP4。竖屏会以当前缸为主体。退出预看后导出跟随当前屏幕。点「全屏看缸」后工具会自动收起，比例不同时画面居中留白。点画面调回工具，「退出全屏」继续窗口预看，「返回观察」回到游戏。窗口预看也可以点「只看缸景」收起工具。从全屏静观进入预看，可用「回到静观」继续看原来的虾。

要打开已同步的副本，点「观察」顶部同步按钮旁的「预览」。在布置空缸时，也可以直接点底部的「看上次的壁纸」。副本会在新标签页播放，回来可以接着造景。保持本机 5174 服务运行即可关闭游戏标签。虾群在壁纸中独立活动，进度只在壁纸的内存里变化。要换缸或更新造景，再同步一次，已打开的壁纸会自动载入新副本。壁纸副本单独存放在本机用户目录，与浏览器养成存档分开。

在游戏里看另一口缸时，「观察」中的「回游戏照料」可以带你回到上次同步的那口缸。它打开游戏存档里的最新进度。想继续用原缸作壁纸，可以点「回到原缸并更新壁纸」，游戏会带你回去并重新同步。想把当前缸换成壁纸，直接点「同步到实时壁纸」。这些操作沿用上次同步的单缸或整组缸取景。想更换取景，在壁纸预看里切换并同步一次。

想在桌面看虾找食，投喂后点「投喂点」，再点「把这次加餐同步到壁纸」。回执里的「同步时有投喂点」表示副本带上了饲料。已发现食物的虾会接着活动，其他虾按各自的节奏找食。过了这次投喂的有效时间再打开壁纸，旧饲料会自然消失。

桌面用固定的窗边远景。同步小图和 MP4 也会把整口缸收进画里。即使在游戏里靠近一只虾，点同步也能直接得到整缸壁纸。旧的近景副本重新打开后自动用远景播放，下一次同步会生成新的整缸小图。游戏里的「跟随它观察」和「轮流观察本缸收藏」仍可近看；轮流观察约每 20 秒换一只，随时能选「只跟随当前这只」或返回整缸。

也可以直接用地址：同步后展开「在 Wallpaper Engine 中打开」，点「复制地址」。在本机 Wallpaper Engine 的「打开壁纸 → 从 URL 打开」粘贴即可，打开时鱼缸服务需要已在运行。希望电脑开机时先等待服务就绪，可选上面的 HTML 入口。

「观察」面板和「壁纸」预看会显示上次同步的缸名、时间和当时的虾数。移走一只虾后，重新打开游戏仍能看到本缸和副本相差几只。数量相同但换过虾时，面板会提示成员有变化。已安排的孵化会计入比较。比如关灯后再同步，第一行显示新的灯态，下一行显示桌面上次载入的版本和仍待确认的灯光变化。Wallpaper Engine 画出新画面后，状态更新为「桌面入口已载入」。同步待孵的一窝后，可以在这里看到孵出了几只、是否已经全部成年。只要整窝后代还在同一口缸，成年后重新同步也能点「看这一窝的成年对照」。有好几窝时，壁纸优先展示待孵的一窝，其次是同缸幼虾，再是最近一窝同缸成虾。在浏览器里打开下载的 HTML 可以预览。若从另一个游戏窗口换了缸，打开的面板也会更新。

已有副本可以直接预览，也可以重新下载入口。新版 HTML 入口在开机后先确认本机播放页能打开。服务刚启动、播放页暂时打不开时，入口保留留影并自动重试。进入播放器后，缺少的场景资源也会自动重读。手动下载过旧入口的玩家需重新下载并在 Wallpaper Engine 中打开一次。

如果资源下载中断，或显卡暂时无法绘制鱼缸，壁纸会提示等待。有整缸留影时会继续显示。播放中遇到持续绘制错误，壁纸会在本机鱼缸服务可用时重新载入上次同步的缸。如果画面自己恢复，壁纸会直接继续播放。启动或换缸后，缺失或损坏的留影会在第一帧画好时为当前窗口补拍。Wallpaper Engine 已暂停时，恢复播放后才重试。

壁纸先打开时，可以回游戏同步鱼缸，原窗口会自动开始载入。如果提示「壁纸副本无法读取」，在「观察」中重新同步一次即可。播放中遇到缺失或读不出的副本，原来的鱼缸会继续播放，重新同步后自动换到新缸景。

同步时按游戏所在屏幕的比例拍摄整缸留影；录制视频期间同步会沿用视频比例。新下载的 HTML 会把这张照片带到播放页，读取最新副本时仍能看到这口缸。已有更新的留影时会先换图，虾群开始播放后照片自动收起。同一个壁纸窗口重新载入时也会先显示上次的留影。

**电脑重启后**，双击项目里的「启动实时壁纸.cmd」就能手动恢复服务。想让鱼缸服务随 Windows 登录启动，双击「设置壁纸自启.cmd」，选 1。以后想关闭，再打开同一个文件选 2。项目搬家后，在新位置选 1 即可更新路径。设置只管理当前用户的鱼缸服务快捷方式；桌面是否随登录播放，由 Wallpaper Engine 自己的启动设置决定。

如果 Wallpaper Engine 先于鱼缸服务启动，入口会先展示整缸留影。通过游戏按钮设到桌面后，再同步就会一起更新开机留影。手动下载的 HTML 保留下载时的照片；想更新这份照片，可以重新下载入口。没有留影时会显示连接提示。服务就绪后，会载入最近同步的缸，画好第一帧就开始播放。日常播放无需打开游戏标签或重新同步。已有鱼缸服务时，手动启动器会直接退出。登录启动器会留在后台等候；关闭先前的开发服务后，它会在原端口接手，沿用最后同步的鱼缸。已设置过旧版自启的玩家，在「设置壁纸自启.cmd」中再选一次 1 即可更新快捷方式。如果端口正被其他程序占用，启动器会每 5 秒再检查一次，等原端口空出来就自动启动。由启动器运行的服务意外退出时，会在原端口自动重试。短时间内连续失败三次后，窗口会保留错误信息。关闭启动器窗口或按 Ctrl+C 可以停止服务或重试。

实时壁纸会跟随 Wallpaper Engine 的帧率设置，直接在浏览器打开时默认 30 帧。在游戏中同步另一口缸后，正在播放的壁纸会在原画面切换。服务暂时离线或新副本未通过校验时，旧缸继续播放。宿主暂停或页面隐藏时会停下动画循环和更新查询。期间仍可在游戏里同步鱼缸，壁纸重新可见且恢复播放时会立即检查最新副本。

三渲二鱼缸放在日光照进来的窗边。缸里的木石、水草与虾保留立体形状、投影和动作，虾册使用同一个体模型生成带细边的肖像。关掉缸灯后，房间仍有窗光，水草出氧和水下灯效随缸灯开关。静观、录制和实时壁纸共用这套光照。

支持全屏的浏览器会在「观察」里显示「全屏静观」，点「结束静观」或按 H 即可回到游戏。浏览器自行退出全屏时也会回到缸边。

静观时点右上角「看整缸壁纸」，可暂时放下近看的那只虾，欣赏自己搭的整缸。点画面可以调出壁纸工具，按 Esc 回到静观，按 H 回到游戏。轮看收藏时，这段时间会留给当前这只虾，回来再继续轮换。在当前游戏页里退出再打开预看，会保留刚选的单缸或整组构图。要把这个选择用到桌面，请在预看里点「同步到实时壁纸」。

想单独看一只收藏虾，可以先跟随它再进入静观。静观时，收藏星和选中光圈会暂时隐去；回到缸边后按你原先的设置显示。同步的壁纸小图、实时壁纸和录下的 MP4 也只展示缸景。

点缸边的孵化消息，就能去幼虾住的缸。点水草间的一只小虾可以观察、拍照，点「看同窝照片」可以一次看全。孩子已经分缸时，可以自己选先去哪口缸。成年后可以查看同窝对照。离开期间跨过多个阶段时，每窝显示最新进展。其余未读消息在虾册标题下的「成长消息」里，已看过的一窝可以从「选育 → 同窝手记」翻回去。

刚孵化时，可以从母虾附近的石头、草根和底砂找起。有的小虾会停下来啄食，有的已经游到隔壁。下次回来，随着小虾长大，它一次会走得更远。

同一浏览器开了多个游戏页时，另一页更新存档后，旧页会提示刷新并暂停自动保存与成长结算。可以继续观赏，刷新后接着最新进度养虾或同步壁纸。

运行 `npm test` 执行自动测试。使用 `npm run dev -- --port 5174` 打开[试用版](http://127.0.0.1:5174/)。正式版和试用版分别保存游戏进度。
