# ThreeAquarium

同一工程内的造景与养虾迁移版。功能和实测边界见 [MIGRATION.md](MIGRATION.md)。

## 打开和操作

双击 D:/Fish tank/打开Three.js水草缸.cmd，或访问 http://127.0.0.1:5173 。

- 拖动旋转，滚轮缩放，方向键平移，R 复位、Esc 取消、V 俯视、H 静观。静观时点「结束静观」或再按 H 返回。底部是一条细操作栏：观察、照料、造景、时间、存档，加上加餐、轻敲玻璃、静观和返回整缸。点分组才展开一小块面板，点外面或按 Esc 收起。「收起」可把整条栏让开，收起后标题下仍显示当前步骤。整缸状态在左上角，点开才看详情。点一只虾，名字和收藏出现在旁边的小卡片上。观察里的「画面」可选高、中、低：高包含焦散、光柱、浮粒和偶尔的气泡；低关掉这些，方便手机。第一次打开会有一句可关掉的说明，关掉后会记住。
- 左上角先看整缸状态（状态良好、觅食中、抱卵）和生态第几天。点开还能看到最年轻的水草种下多久。点一只虾可以改名、标成收藏，并看到饥饿、压力、性别和是否抱卵。倒计时同时写生态日和大约的现实时间。收藏排在前面，点一下就能选中并跟随。缸里的星标默认只在指向或选中时出现，也可以打开「显示收藏星标」。
- 加餐和轻敲玻璃先点按钮对准，光标会变成十字，再点你要作用的位置。加餐是偶尔的零嘴：虾平时自己吃草叶和沉木上的生物膜。加餐不会叠多次，也不会把四周的抱卵缩短。
- 成熟、吃得稳、不紧张的母虾才会抱卵，大约 28 个生态日后孵出 1 只幼虾（现实约 4.7 天）；幼虾大约 75 个生态日才长成（现实约 12.5 天）。虾群到 36 只不再新抱卵，上限仍是 50。手填数量收在「照料」。
- 默认游戏 1 天 = 现实 4 小时（6 倍）。水草、抱卵、生物膜和离线结算都走这个倍率；虾在画面上的走动、摄食和饥饿仍按真实秒，不会看起来被快放。水草按生态日生长（后景约 12 天、中景约 24 天、前景约 16 天到峰值，现实大约 2–4 天），高度跟着长；阶段或修剪才整缸重建。整天跳跃收在「时间」。
- “造景”里编辑造景、切换工具。选植物或木石，再点裸露底床移动；按钮控制旋转、倾斜、埋深。移除会先确认，刚移除的可以用撤销放回去。编辑时虾模拟会停住。底床材料用 0–4 编号；坏掉的土壤类型读档时改回深棕水草土，不再停用自动保存。
- 土壤工具按住底床操作；Esc取消笔划，最近20次本页造景变更可撤销重做。
- 主菜单可新建空缸，依次完成铺土→木石→种植→注水；新建前会确认，并保存上一缸。支持快进生长和局部修剪。窄屏把同一条底栏折成两行，分组和常用操作都在屏内，点分组再展开，按钮至少约 44 像素高。每个操作都会在画面上方留下一句说明。
- 15秒自动保存完整状态；v4 JSON导出导入，名字和收藏写在虾的身份上，刷新还在。旧的抱卵进度会按默认名字和未收藏读入。后出生的幼虾叫「幼虾1」「幼虾2」。原Unity鱼缸和对应虾JSON可同时只读导入，失败不覆盖旧档。

浏览器不写原Unity存档。浏览器存储有清除风险，长期保存请导出JSON。

## 开发

在本目录依次 npm ci、npm test、npm run build、npm start。开发用 npm run dev，先停止5173生产服务。生产读取dist，修改代码后build并刷新。服务仅绑定127.0.0.1，开发/生产共用public/assets。

gameplay/session负责完整流程和事务；tank-runtime/hardscape负责目录和支撑；substrate/soil-view负责底床；ecology/pruning负责成长/剪切；creatures/swimming/habitat负责行为/运动；population/foot-contacts/plant-contacts负责个体和动态接触；assets/crafted/water负责材质/水体；layout/editor保留M2兼容。tools有导出/转换/检查源码，复制源存档不向网页公开。来源和许可见public/assets/ATTRIBUTION.md。

## 验证与限制

Node检查见 npm test。verify-complete、verify-setup、verify-full、verify-capacity使用同一Playwright页并恢复测试前存储，结果在evidence的JSON；旧脚本是阶段历史。投喂和轻敲在检查脚本里改为直接调用落点。底栏分组默认收起，这些脚本在鱼缸就绪后调用 showDock('all')。

RX6600/1600×900/50虾/阴影开启约60FPS。微信打包/真机、长时多机型尚未测试；跨引擎灯光和镜头不保证逐帧一致，最终画面待用户实际检查。资源约345.2MiB、dist代码约0.72MiB，不是微信首包体积。旧Unity源和游戏仍保留。
